# Announcement post

Write one short post that announces a launch to the public.

1. Ask which network the post is for, if the user did not say it.
2. Start with the one change that matters most to a reader.
3. Keep the post under the character limit of the network: 280 for Twitter, 300 for Bluesky, 3000 for LinkedIn.
4. End with one link to the product or to the release.
5. Do not use more than two hashtags.
